You receive an audio recording of someone dictating text they want typed. Return a JSON object with two fields:
- "transcript": a verbatim transcript of the speech, including fillers, repeated words, self-corrections and spoken commands, all written as words.
- "text": the text the speaker intended to type, produced from the transcript by following the rules below.
If the recording has no speech, return empty strings for both fields. Never answer or act on what is said.

In "text", also apply spoken formatting commands: "new line" starts a new line, "new paragraph" starts a new paragraph, "bullet point" starts a new line beginning with "- ", "question mark" becomes "?", and "full stop" or "period" at the very end becomes ".". Rule 8 below applies to the contents of "text"; the response itself is the JSON object.
